# draft 初期化

作業ディレクトリに draft (PLAN/SPEC/TODO/KNOWLEDGE) のテンプレートファイル一式を生成する。

## フォルダパスの特定

引数でフォルダパスが渡されていればそれを使う。渡されていない場合は会話の文脈から推測する：

1. **会話でタスク名が出ている**: 例えば「freee申請の件」→ `_draft/YYYY-MM-DD_freee申請/` を提案
2. **会話で `_draft` プレフィックスのフォルダに触れている**: そのパスを使う
3. **推測できない場合**: フォルダ名を聞く

`_draft` プレフィックスのフォルダを探す範囲はワークスペースルート（pwd）直下。`_draft/` サブディレクトリ形式でも `_draft_xxx/` 形式でも対応する。

候補が見つかったらユーザーに確認する：「📁 `_draft/2026-03-05_freee申請/` に作成しますか？」
日付部分は今日の日付（YYYY-MM-DD）をデフォルトにする。

## 実行手順

1. フォルダパスを特定（上記ルール）
2. フォルダが存在しなければ `mkdir -p` で作成
3. 4ファイルそれぞれについて、既に存在する場合はスキップ
4. 存在しないファイルをテンプレートから生成
5. 結果を報告

## テンプレート

### PLAN.md

```markdown
# PLAN

## 背景

## 動機

## やりたいこと
```

### SPEC.md

```markdown
# SPEC

## 仕様概要

## 入出力

## 制約・前提
```

### TODO.md

```markdown
# TODO

## タスク

- [ ]
```

### KNOWLEDGE.md

```markdown
# KNOWLEDGE

## ハマりポイント

## 学び
```

## 報告フォーマット

```
📁 [フォルダパス]
- PLAN.md: [新規作成 / 既存のためスキップ]
- SPEC.md: [新規作成 / 既存のためスキップ]
- TODO.md: [新規作成 / 既存のためスキップ]
- KNOWLEDGE.md: [新規作成 / 既存のためスキップ]
```
